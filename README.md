# CampusFind
Lost & found app for University of Lahore students.

- **App name / icon:** CampusFind (own icon)
- **Members:** Ayesha Murtaza(70149530), Maham fatima (70146948), 

## Stack
Native Android, Java, XML layouts, Material Design 3 (Material Components), SQLite (local database),
SharedPreferences (session), salted SHA-256 password hashes, Google Fused Location Provider (GPS).

## Features completed
F1-F12 (icon, login/register, bottom navigation + profile, home list, details, report form,
current location, database, session/logout, open in maps, nearby, filter + mark as returned).

## Run
1. Open the project in Android Studio and let Gradle sync.
2. Run on an emulator (set a location in Extended controls) or a phone.
